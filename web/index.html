      Eight-week interview plan

      Built for a full-time search: mornings on data structures and algorithms, afternoons on applications, system design, and behavioral practice.

      How to run it. Each week has a checklist. Check things off as you finish them; progress is saved. The current week is highlighted and its focus shows up on the Today tab.

      Problem rules. Set a 30-minute timer per problem. If you're stuck at 20 minutes, read the approach (not the code), then write it yourself. Log every problem's pattern in a notebook — the pattern is what transfers, not the problem.

      Weighting. This plan is tuned for senior and staff platform / AI-infrastructure loops: system design starts in week 2 on home turf and runs two cases a week from week 3, and behavioral prep centers on leadership signals — ownership, cross-team influence, incident leadership, mentoring. Algorithms stay daily because most loops still open with a coding screen.
